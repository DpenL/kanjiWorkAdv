Dictionaries & core data CC BY-SA

JMdictThe word dictionary (JP↔EN/DE/…, XML). Backbone for any vocabulary mechanic.
KANJIDIC2Per-kanji readings, meanings, stroke counts, grades, frequency, JLPT. The kanji database.
KRADFILE / RADKFILEKanji ⇄ radical decompositions — the data behind component/radical mechanics.

Strokes & handwriting

KanjiVG CC BY-SASVG stroke paths for every jōyō kanji — powers tracing, stroke-order animation (see the tracing kiosk next to this one), and lightweight handwriting matching.
TegakiOpen-source handwriting recognition engines if you outgrow stroke matching.

⚖ Data licenses — read before shipping

EDRDG files (JMdict, KANJIDIC2, KRADFILE) and KanjiVG are CC BY-SA: credit the source, and if your app displays dictionary data live, the acknowledgement must be visible on those screens. Derivative data files inherit BY-SA (share-alike). Tatoeba is CC BY (credit only). Commercial use is allowed; attribution is not optional. Keep one visible credits screen in every prototype and you're fine.
